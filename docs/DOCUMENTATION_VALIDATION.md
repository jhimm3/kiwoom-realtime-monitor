# 문서 정리 검증 기록

기준: 2026-09-22 · 대상: e0b9 / `codex/release-2.1.0` · 제품 2.1.0

## 확인한 항목

- 기존 Markdown 178개(제3자 고지 5개 포함)를 파일별 분류했고 미분류 파일은 없다.
- 단계별 보고서·이전 릴리즈·구형 명세 135개를 아카이브로 이동했다. 현재 문서 재작성의 이전 전문은 별도 스냅샷으로 남긴다.
- 정리 전 178개 원문과 첨부/이전 초안 7개를 ZIP에 바이트 단위로 보존하고 SHA-256 및 ZIP 무결성을 확인했다.
- 현재·아카이브 Markdown의 상대 파일 링크, 현재 코드펜스 짝, 새 모듈 지도의 실제 Python 경로를 검사했다. 로컬 링크 679개에서 끊긴 링크 0개, 현재 문서 코드펜스 오류 0개, 모듈 경로 누락 0개다. `git diff --check`도 통과했다.
- 보존한 연구 요청 예제 15개와 API/모의계약 코드블록·필드/표의 의미를 확인했다. 현행 상태 표현을 정정했으며 API나 DB 구조를 변경하지 않았다.
- 적용 전 모든 원문 해시와 대상 경로를 확인하고, 적용 후 산출물 190개의 해시와 기존 미커밋 코드/테스트의 해시가 모두 일치함을 확인했다.

이동 전후 파일과 원본 해시는 [문서별 목록](archive/2026-09-22/document-inventory.json), 원문은 [보존 ZIP](archive/2026-09-22/original-documents.zip)에 있다. 읽기용 아카이브는 안내와 링크를 정리했으므로 원문과 바이트가 같다는 주장은 ZIP 항목에만 적용한다.

## 검증 범위의 한계

이번 작업은 문서 정리·기획이다. 제품 코드를 변경하지 않아 앱 전체 테스트를 새로 실행하지 않았다. 과거 보고서의 테스트 수치와 운영 결과는 당시 기록이다. 실제 NAS 최신 이미지·실브로커·장시간 검증, 대신 수집·네이버 과거 본문 도달·LLM 학습을 이번에 수행하지 않았다.

GitHub 릴리즈와 기획에 인용한 공식 제공기간/도움말은 확인했지만 모든 외부 URL·공개 GitHub Pages 과거 주소를 전수 실행 검증하지 않았다. 파일별 과거 경로는 이동 목록으로 추적할 수 있다. 보고서에 언급된 미보유 JSON 등 증거의 한계는 [남은 작업](OPEN_ITEMS.md)에 유지한다.
