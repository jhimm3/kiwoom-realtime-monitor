# Phase 3 순위·신고가 결합 기록

범위: REST 조회 결과를 화면용 종목 데이터로 결합한다. 아직 GUI 자동갱신과 WebSocket은 연결하지 않는다.

## 구현됨

- `ka00198`의 실시간 종목조회순위 목록을 Top 20 기준으로 사용
- `ka10016`의 5·20·250거래일 신고가 목록을 종목코드로 대조
- 화면용 데이터: 순위, 종목코드, 종목명, 등락률, 신고가 기간
- 모의투자 확인용 `scripts/preview_top_stocks.py`

## 표시 규칙

- `250일`은 **250일 신고가(52주 근사)**를 뜻한다.
- 신고가 미해당 종목은 `-`로 표시한다.
- 상장 후 최고가는 아직 표시하지 않는다.

## 다음 단계

이 데이터를 GUI의 표에 연결하고, 사용자가 누르는 새로고침 기능을 추가한다. 이후 WebSocket 실시간 체결 데이터를 결합한다.
