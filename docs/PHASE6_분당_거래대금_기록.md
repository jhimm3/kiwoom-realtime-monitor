# Phase 6 분당 거래대금 기록

범위: `0B` 체결 틱을 접속 이후 수신한 데이터 기준으로 1분 OHLCV로 묶고 거래대금을 계산한다.

## 계산식

```text
분당 거래대금(억원) = 거래량(V) × (고가(H) + 시가(O) + 저가(L) + 종가(C)) ÷ 4 ÷ 100,000,000
```

- 시가: 해당 1분의 첫 체결가
- 고가·저가: 해당 1분 체결가의 최댓값·최솟값
- 종가: 가장 최근 체결가
- 거래량: 개별 체결량(FID `15`) 합계

## 구현됨

- 종목별 1분 OHLCV 집계
- 현재 1분의 거래대금(억원)을 표에 실시간 표시
- 최근 5개·60개 수신 1분봉 합산 기능
- 영웅문 산식 단위 테스트

## 제한

앱을 켠 시점부터 체결을 모으므로, 처음 켠 직후의 분봉은 그 시점 이후 수신분만 포함한다. 과거 분봉을 보완하는 REST 조회는 다음 단계에서 추가한다.

## 다음 단계

1분봉을 REST 과거 분봉과 연결해 장중 전체 값을 보완하고, 5분·60분·1일 거래대금을 화면에 추가한다.
