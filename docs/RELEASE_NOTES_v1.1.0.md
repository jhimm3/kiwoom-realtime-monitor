# 키움 실시간 모니터 1.1.0 변경 내역

> 2026-08-22

## 추가

- Google Drive `내 드라이브/키움 실시간 모니터` 폴더를 이용한 설정·테마 동기화
  - Google 로그인 연결·해제
  - 수동 업로드·다운로드
  - 설정과 테마 / 설정만 / 테마만 대상 선택 및 분리 저장
  - 시작 시 자동 다운로드, 변경 후 자동 업로드, 종료 시 자동 업로드를 각각 선택
  - 연결 전에는 동기화 요청을 실행하지 않음
  - Drive 통신은 별도 작업으로 실행해 메인 표를 멈추지 않음
- 테마 DB 전용 수동 JSON 저장·불러오기
  - 테마, 종목 연결, 테마 색, 별칭, 등록 종목 포함
  - 일반 설정, 필드 구성, API 키, 로그는 제외

## 변경

- 시작 자동 다운로드는 창 생성 전에 적용하고, 수동 다운로드는 재시작 없이 표와 설정에 즉시 반영
- 종료 시 이미 업로드가 끝난 상태라면 Google Drive 통신을 다시 시작하지 않도록 개선
- 장 종료·주말에는 분봉 보완을 시작하지 않도록 보완
- Google 로그인·동기화 완료 뒤 관리 탭의 연결 상태를 즉시 갱신
- Google Drive 관련 의존성과 재현 가능한 잠금 버전을 기록

## 검증

- Python 3.13 / Windows 환경에서 단위 테스트 44개 통과
- 의존성 검사 통과
