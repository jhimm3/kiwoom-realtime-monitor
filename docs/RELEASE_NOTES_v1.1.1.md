# 키움 실시간 모니터 1.1.1 변경 내역

> 2026-08-23

## 수정

- 기본 설정 창의 크기를 PC별 로컬 설정으로 저장·복원
  - 기본 크기: 680×650
  - 사용자가 가로·세로 크기를 자유롭게 조절 가능
- 관리·프로그램 정보 탭에서 창 테두리를 드래그할 때 내용 크기 때문에 창이 갑자기 커지거나 줄어들지 않던 문제 수정
- 기본 설정 창의 최소 크기 계산을 조정해 탭을 바꾼 뒤에도 작은 크기로 정상 조절되도록 개선
- Google Drive 동기화 시 창 크기와 표 열 폭은 계속 로컬 PC별 상태로 유지
- 거래대금 표 열 제목에서 단위 표기 `(억)` 제거
- 신고가 행 강조 단계가 선택 단계 이상(관심 → 관심·주의·불, 주의 → 주의·불)에서 계속 적용되도록 수정
- 앱 시작 직후에도 신고가 근접 강조가 바로 계산·표시되도록 수정
- 실시간 현재가 갱신 시 현재가 셀만 기본 배경색으로 바뀌던 문제를 수정해 행 전체 강조를 유지
- PyInstaller 폴더형 실행 파일에서 기본 OCR 모델을 실행 파일 옆 `data` 경로에서 찾도록 보완
- 설치 프로그램은 앱 본체를 `Program Files\\KiwoomMonitor`에 설치하고, API 키·설정·테마 DB·로그 등 개인 데이터는 `%LocalAppData%\\KiwoomMonitor`에 별도로 보관하도록 변경
- 프로그램 제거 시 개인 데이터까지 함께 삭제할지 선택 가능

## 정리

- 더 이상 사용하지 않는 개발용 확인 스크립트와 빈 폴더 표식 파일 제거
- 배포용 PyInstaller 도구와 실행 파일 생성 절차를 정리

## 검증

- Python 3.13 / Windows 환경에서 단위 테스트 46개 통과
