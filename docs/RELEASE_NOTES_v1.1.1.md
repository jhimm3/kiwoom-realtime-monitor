# 키움 실시간 모니터 1.1.1 변경 내역

> 2026-08-23

## 수정

- 기본 설정 창의 크기를 PC별 로컬 설정으로 저장·복원
  - 기본 크기: 680×650
  - 사용자가 가로·세로 크기를 자유롭게 조절 가능
- 관리·프로그램 정보 탭에서 창 테두리를 드래그할 때 내용 크기 때문에 창이 갑자기 커지거나 줄어들지 않던 문제 수정
- 기본 설정 창의 최소 크기 계산을 조정해 탭을 바꾼 뒤에도 작은 크기로 정상 조절되도록 개선
- Google Drive 동기화 시 창 크기와 표 열 폭은 계속 로컬 PC별 상태로 유지

## 정리

- 더 이상 사용하지 않는 개발용 확인 스크립트와 빈 폴더 표식 파일 제거
- 현재 사용하지 않는 PyInstaller 관련 가상환경 패키지 제거

## 검증

- Python 3.13 / Windows 환경에서 단위 테스트 46개 통과
