# 1.1.12 변경 내역

- `ka10081`의 수정주가 일봉을 기준으로 KRX와 NXT를 합산해 5일·20일·250일 최고가를 계산하도록 바꿨습니다. 액면분할·병합 등 수정주가가 반영된 차트 기준과 맞춥니다.
- `ka10094` 수정주가 연봉 연속조회로 **1985년 이후 역사적 신고가**를 추가했습니다. 표의 `신고가` 열 머리글을 누르면 `신고가(5) → 신고가(20) → 신고가(250) → 신고가(역)` 순서로 바꿀 수 있습니다.
- 역사적 신고가는 종목별 Kiwoom 날짜에 하루 한 번, 다른 초기 조회 작업이 끝난 뒤 가장 낮은 우선순위로 갱신합니다. 당일 고가가 저장된 역사적 최고가를 넘으면 실시간 고가도 즉시 반영합니다.
- 역사적 신고가 결과는 로컬 SQLite에 저장합니다. 설정·테마 백업이나 Google Drive 동기화에는 포함하지 않습니다.
