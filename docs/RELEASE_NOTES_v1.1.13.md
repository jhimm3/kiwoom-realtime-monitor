# 1.1.13 변경 내역

- 역사적 신고가 계산을 연봉에서 끝내지 않고, 수정주가 이벤트가 있는 연도와 최고가 후보 연도를 월봉으로 확인한 뒤 필요한 달만 일봉으로 정밀 검증하도록 개선했습니다.
- 액면분할·병합 등 수정 이벤트의 종류·비율·발생일과 고가 근거 봉을 SQLite에 저장합니다. 다음 조회부터는 마지막 확인 이후 연봉을 먼저 확인하고 필요한 구간만 증분 조회합니다.
- 이미 계산된 수정주가 기준 250일 최고가가 연봉 또는 보정된 월봉 최고가 이상이면 더 세부적인 월봉·일봉 요청을 생략해 API 사용량을 줄였습니다.
- 기본 설정의 신고가 탭에 `헤더 클릭 순환` 항목을 추가했습니다. 5일·20일·250일·역사적 중 선택한 신고가만 기존 순서대로 전환되며, 이 설정은 로컬 저장과 Google Drive 설정 동기화에 포함됩니다.
- 배포 파일을 만들지 않고 최신 소스와 기존 사용자 데이터로 기능을 확인할 수 있는 테스트 앱 실행 도구를 추가했습니다.
