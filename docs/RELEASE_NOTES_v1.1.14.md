# 1.1.14 변경 내역

- 역사적 신고가의 연봉·월봉·일봉 조회 기준일을 모두 조회 당일로 통일해, 여러 차례의 액면분할·병합·감자 이후에도 현재 보유 주식 1주와 비교할 수 있는 수정주가로 계산합니다.
- 키움 월봉·일봉이 이미 수정주가로 제공되는 경우 다시 수정비율을 적용하지 않도록 보완하고, 오래된 가격이 비정상적으로 수백만 원대로 확대되는 문제를 방지했습니다.
- 연봉·월봉·일봉 사이의 수정주가 기준이 다른 종목에서도 현재 기준으로 일관된 값을 선택하도록 역사적 신고가 계산을 보강했습니다.
- 신고가 헤더를 눌러 기간을 전환할 때 표 전체를 여러 번 다시 그리지 않도록 처리해 거래대금·거래강도 강조가 깜빡이는 현상을 제거했습니다.
- 업데이트 도우미·OCR 모델·알림음·아이콘·라이선스처럼 변경되지 않은 릴리즈 자산은 검증본을 재사용하고, 앱 본체·설치 파일·부분 업데이트 파일만 새 버전에 맞춰 재생성하도록 배포 기준을 명확히 했습니다.
