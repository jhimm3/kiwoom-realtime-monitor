# 1.1.15 변경 내역

- 여러 이미지를 한 번에 OCR 테마 업데이트로 가져오고, 색상 배지와 이유 문장이 섞인 표에서 테마 열을 더 정확하게 분리하도록 보완했습니다.
- 이미지 OCR의 반복 오인식(`개벌이슈`, `로봇시`, `바이외제약`, `달중국`, `동신` 등)을 정규화하고, 신규 추가·텍스트·Excel·OCR마다 구분자와 제외 테마를 따로 저장하도록 개선했습니다.
- 테마 일괄 수정에서 `해운/이란`처럼 구분자를 입력하면 하나로 합쳐진 테마를 여러 테마로 안전하게 분리합니다.
- 텍스트 테마 업데이트에서 `#mRNA` 같은 소분류를 별도 테마로 추가할지 선택할 수 있습니다.
- 여러 종목명이 붙은 입력을 한 글자 오타까지 고려해 분리하고, 정확히 확인된 종목을 먼저 제외한 뒤 남은 이름만 테마 문맥과 함께 유사검색할 수 있습니다.
- KRX 상장목록과 KIND `상호변경안내` 공시를 연동했습니다. 과거 종목명은 자동 확정하지 않고 사용자가 현재 종목으로 연결할지 확인한 후 별칭으로 저장합니다.
- NXT 일봉 조회가 일시적으로 실패해도 마지막 정상 KRX+NXT 250일 신고가를 유지해 값이 조회할 때마다 흔들리지 않도록 했습니다.
- 테마 분리·종목명 변경 과정의 외래키 오류를 방지하고, 새 설정과 종목명 이력이 로컬·Google Drive 백업에 포함되도록 보완했습니다.
