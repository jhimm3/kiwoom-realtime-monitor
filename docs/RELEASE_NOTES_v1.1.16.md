# 1.1.16 변경 내역

## 실시간 거래대금 안정성

- KRX와 NXT의 누적 거래량·거래대금을 시장별로 분리해, 두 시장 체결이 섞이면서 1분 거래대금이 흔들리는 문제를 방지했습니다.
- 구독 종목 변경 때 전체 소켓을 다시 연결하지 않고 기존 연결에서 구독만 갱신합니다.
- 신규 구독·재접속 직후의 누적 공백분이 현재 1분 거래대금에 한꺼번에 더해지지 않도록 기준값을 초기화합니다.

## 화면 안정성

- 실시간 순위표를 다시 그릴 때 테마 배지를 중복 생성하지 않도록 처리 순서를 조정해, 표 크기가 순간적으로 흔들리는 현상을 줄였습니다.
- 메인 창의 마지막 위치와 크기를 저장하고 다음 실행 때 복원합니다.
- 모니터 구성이나 해상도가 바뀌어 저장 위치가 화면 밖이면 안전한 기본 위치에서 엽니다.

## 포함 범위

- v1.1.15 이후 뉴스 기능 개발 직전 복원 지점까지의 실시간 체결·거래대금 및 UI 수정 사항을 포함합니다.
- 개발 중인 종목 뉴스창, 뉴스 API 및 AI 원문 분석 기능은 이번 안정판에 포함하지 않았습니다.
