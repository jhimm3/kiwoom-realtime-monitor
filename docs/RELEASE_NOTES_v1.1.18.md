# 1.1.18 변경 내역

## 실시간 메인표와 뉴스 기능 분리

- 뉴스 수집·사건 묶음·AI 분석·화면 갱신을 별도 프로세스로 옮겨 뉴스창 작업이 메인 실시간 순위표를 멈추거나 함께 종료시키지 않도록 했습니다.
- 뉴스 기사와 AI 결과를 메인 DB가 아닌 `news.sqlite3`에 분리 저장합니다. 기존 메인 DB의 뉴스 자료는 최초 실행 때 뉴스 DB로 안전하게 옮깁니다.
- 빠르게 여러 종목을 선택하면 중간 요청은 버리고 마지막으로 선택한 종목만 처리하며, 사건 묶음 계산 중에도 기존 뉴스 화면을 유지합니다.
- 저장된 AI 결과는 기사별 반복 조회 대신 한 번에 읽어 화면 전환 때 발생하던 짧은 멈춤을 줄였습니다.

## AI 분석 연속성과 비용 절약

- 이미 완료한 AI 분석은 로컬 뉴스 DB에서 재사용합니다.
- Google Drive의 설정 동기화에 AI 분석 결과 전용 백업을 추가해 다른 PC에서도 같은 기사를 다시 분석하는 API 비용을 줄입니다. 뉴스 원문 전체 DB는 백업하지 않습니다.
- 자동분석 중 한 건이 실패하거나 뉴스 수집과 분석 완료 시점이 엇갈려도 남은 후보를 다시 확인해 다음 분석을 계속합니다.
- 뉴스 프로세스가 다시 시작되어도 현재 종목의 최근 자동분석 후보를 복구합니다.

## 뉴스창 표시 방식

- 뉴스창 표시를 `독립 창`, `메인창과 함께 앞으로`, `메인창 옆에 고정` 중에서 선택할 수 있습니다.
- 연결 또는 옆 고정 모드에서는 메인창과 뉴스창 어느 쪽을 선택해도 두 창이 함께 앞으로 오며, 실제 입력은 사용자가 선택한 창에 유지됩니다.
- 메인창 최소화·복원·종료를 뉴스창과 연동하고, 작업표시줄 그룹과 앱 아이콘을 통일했습니다.
- 뉴스창은 닫은 뒤에도 가벼운 대기 상태로 재사용하며, 메인 앱 종료 시 함께 정리됩니다.

## 성능과 안정성

- 동일 사건 묶음에 필요한 제목 정규화·핵심 숫자 추출 결과를 기사별로 한 번만 계산해 대량 기사 처리 비용을 줄였습니다.
- 뉴스창 종료 시 진행 중인 수집·분류·AI 작업을 안전하게 정리해 간헐적으로 뉴스창이 닫히거나 다음 분석 버튼이 비활성화되던 문제를 보완했습니다.
- 뉴스 전용 프로세스 제어, DB 분리·이관, AI 결과 일괄 조회와 창 동작에 대한 회귀 테스트를 추가했습니다.
