# 키움 실시간 모니터 1.1.2 변경 내역

> 2026-08-23

## 설치·업데이트

- 앱 본체를 `Program Files\\KiwoomMonitor`에 설치하고, API 키·설정·테마 DB·로그는 `%LocalAppData%\\KiwoomMonitor`에 사용자별로 보관
- 제거할 때 개인 데이터까지 함께 삭제할지 선택 가능
- 프로그램 정보 탭에 GitHub Release 기반 `업데이트 확인` 추가
- 부분 업데이트 ZIP을 만들어 변경 파일만 배포할 수 있는 도구와 배포 규칙 추가

## 기본값

- 거래대금 강조 기준: 1분 40억, 5분 200억, 60분 2,400억, 1일 57,600억
- 1분 거래강도 기준: 관심 0.05, 주의 0.1, 불 0.2
- 신고가 기준: 관심 15%, 주의 10%, 불 5%; 관심부터 행 강조
- 거래강도 소수점 4자리 및 현재 필드 표시·순서·폭을 신규 설치 기본값으로 적용

## 검증

- Python 3.13 / Windows 환경에서 단위 테스트 46개 통과
