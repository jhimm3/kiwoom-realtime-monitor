# 1.1.20 변경 내역

## 자동 매매일지와 전략팩

- 키움 과거 체결을 날짜별로 불러오고 당일 같은 종목을 기본 묶음으로 구성합니다. 잔고가 0이 된 뒤 다시 진입한 거래는 회차별로 나눠 돌파·눌림·시가베팅·상따·신규주·종가베팅·과대낙폭·낙주 등을 별도 판정합니다.
- 예정 수수료·세금과 키움 정산 실제 비용을 구분하고, 매수·매도 수량과 잔고 흐름을 기준으로 분할매수·분할매도를 판정합니다.
- PDF·스크립트를 검토 가능한 전략팩으로 만들고 기본분석 우선, 전략팩 우선, 함께 표시, 신뢰도 조건부 자동 교체를 선택할 수 있습니다. 강의 원문과 개인 자료는 배포본·GitHub에 포함하지 않습니다.
- 진입 순간의 실시간 순위, 거래대금, 테마와 테마 내 순위, 신고가 거리, 뉴스, 호가·매수세, 프로그램매매, 외국인·기관 수급, 코스피·코스닥 시장 상태를 스냅샷으로 연결합니다.

## 매매 차트와 복기

- 전일과 당일 1분봉, 5분봉, 일봉을 제공하며 최대 6개 차트를 독립 창에서 함께 볼 수 있습니다. 코스피·코스닥 및 다른 종목도 비교할 수 있습니다.
- B/S 체결 꼬리표에 시각·가격·수량을 표시하고 선택한 체결 위치로 자동 이동합니다.
- 5·10·20·60·120 이동평균선, 1분·일봉 거래대금 기준선, 선·가로선·세로선·사각형·텍스트 그리기와 개별 삭제를 제공합니다.
- 현재 보이는 봉 범위에 맞춰 가격축을 다시 계산하고 가격대별 호가 단위를 사용해 5~15개의 가격 눈금을 자동 표시합니다.
- 분봉·일봉과 복기 내용을 고화질 이미지로 함께 저장하며 그린 도형과 체결정보 표시 설정도 반영합니다.

## TOP20 거래대금 지수와 메인 표

- 30초마다 확정한 상위 20종목을 다음 30초 구간에 적용하고 두 구간을 1분으로 합산해 DB에 저장합니다.
- 코스피·코스닥·시장 미확인 금액을 누적 막대로 나누고 수집 중단 구간과 마우스 상세 금액을 표시합니다.
- 과거 날짜와 1분·5분·60분·일봉을 조회하고, 통계 창에서 최근 1주·1개월·1년 시간대 평균 및 정규장 TOP20/전체시장 비율을 확인할 수 있습니다.
- 테마 머리글을 누르면 20위 내 포함 종목이 많은 테마부터 묶고 같은 테마 안에서는 등락률순으로 표시합니다. 다시 누르면 실시간 순위순으로 돌아갑니다.
- 메인 상단에는 실행환경 선택 대신 API 연결 상태와 버전을 표시합니다.

## 실시간·데이터 안정성

- KRX·NXT 시장별 누적 거래대금 기준선을 분리하고 신규 편입·재진입 때 과거 누적값이 현재 1분 거래대금으로 섞이지 않게 합니다.
- 실시간 분봉과 누적거래대금, 당일 고가, 일봉과 시장지수를 DB에 저장하고 장 종료 후 또는 다음 장 시작 전 미완성 자료를 제한적으로 보완합니다.
- 뉴스와 매매일지를 별도 프로세스·DB로 분리하고 빠른 종목 전환, AI 분석 실패, 이미지 OCR 중에도 메인 실시간 표가 계속 갱신되도록 했습니다.
- 앱 종료 시 연결된 자식 프로세스를 정리하고 각 창의 마지막 위치·크기를 복원합니다.
- 429, WebSocket 비정상 종료·재연결과 최종 미복구 분봉·일봉을 진단용으로 기록하되 기존 실시간 호출 순서는 변경하지 않습니다.
