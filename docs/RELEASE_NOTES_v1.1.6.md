# 키움 실시간 모니터 1.1.6 변경 내역

## 자동 업데이트

- 앱 종료를 기다리는 단계부터 파일 교체·재실행까지 별도 진행 창에 표시합니다.
- 업데이트 도우미를 STA 모드로 실행해 진행 창이 보이지 않거나 파일 교체가 실행되지 않던 문제를 수정했습니다.
- Windows PowerShell에서 한글 스크립트를 잘못 읽어 업데이트가 시작되지 않던 문제를 수정했습니다.
- 업데이트 단계와 오류 원인을 `%LocalAppData%\\KiwoomMonitor\\updates\\apply_update.log`에 기록합니다.

이번 버전은 자동 업데이트 도우미 자체를 수정한 버전입니다. 기존 1.1.4·1.1.5 설치본에서는 1.1.6 설치 파일을 한 번 실행해 설치하세요.
