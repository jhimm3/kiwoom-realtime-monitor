# 키움 실시간 모니터 1.1.7 변경 내역

## 일봉·거래대금 안정화

- 일봉 조회를 `ka10081`로 통일하고, 전일 거래대금은 일봉 응답의 직접값 `trde_prica`를 사용하도록 변경했습니다.
- 추정 수식으로 계산하던 전일 거래대금을 제거해 분봉 합계 비교의 기준값을 정확하게 만들었습니다.
- 종목별 최근 일봉 데이터를 로컬 DB에 보관합니다. 앱 시작·장외·주말에도 저장된 전일 거래대금을 먼저 표시합니다.
- 일봉 데이터는 종목별 최근 30개 응답 범위로 저장하고, 30일이 지난 데이터는 자동 정리합니다.
- 당일에 아직 갱신하지 않은 종목만 `ka10081`로 다시 조회하며, 새 응답에서 달라진 데이터만 수정합니다.

## 분봉 이력·개발 확인

- 종목별 최근 730개 1분봉을 메모리에 유지하고, 로컬 DB의 분봉 이력은 30일 보관 후 자동 정리합니다.
- 개발자 확인용으로 분봉 합계와 일봉 직접 거래대금을 비교하는 월별 CSV를 갱신합니다.
