# 2.1.0 변경 내역

2.1.0은 개인 NAS가 앱과 독립적으로 시장·뉴스·계좌 자료를 수집하는 구조를 완성하고, 연구 후보를 안전한 모의운용으로 연결하는 기반을 추가한 릴리스입니다. 실시간 순위가 항상 최우선이라는 원칙 아래 NAS 장애전환, 장중 표시, 계좌 관리와 뉴스 처리에서 확인된 병목과 오류도 함께 보완했습니다.

## 자동 연구와 모의운용 기반

- 저장된 연구 결과에서 동결 후보를 게시하고, 별도 합격 기준과 실제 Shadow 근거를 통과한 후보만 READY 모의운용 명세로 만들 수 있습니다.
- 계좌별 단일 실행 소유권, 주문 비활성 시작, 손실·자료 공백·대사 상태 안전 gate, 중지·재개·재시작 복구를 연결했습니다.
- 지속 runner가 NAS에 저장된 TOP20과 완료 분봉을 읽어 같은 입력을 중복 처리하지 않고, 실제 상세 체결을 계좌별 매매일지 근거로 투영합니다.
- 30분 반복 검사에서 핵심 62개 회귀를 151회, 총 9,362개 검사로 반복해 실패와 지속 메모리 증가가 없음을 확인했습니다.

## 다중 계좌와 런타임 인증

- 실전·모의 키움 인증정보를 컨테이너 환경변수에서 분리해 NAS의 암호화 저장소와 계좌별 binding으로 관리합니다.
- 계좌 연결·해제·삭제, 표시 이름 변경과 기본 시세·모의운용 역할을 실행 중에 관리할 수 있습니다.
- 실전과 모의투자의 서로 다른 TR 제한, 토큰, WebSocket, 요청 queue를 분리하고 계좌 신원과 매매 기록을 보존합니다.
- HTTPS 역방향 프록시와 고정 gateway 경계를 문서화하고 인증 API의 revision·scope 검증을 강화했습니다.

## 실시간 순위와 장애전환

- `ka00198` 최신 20종목 완성본을 저장하기 전에 검증하고, 직전 회차나 부분 응답은 짧은 간격으로 다시 요청합니다.
- 30초 순위 경계에는 저우선순위 TR을 미뤄 신고가·기본정보·분봉 보완이 실시간 순위를 막지 않도록 했습니다.
- NAS 장애 시 이 PC의 REST와 WebSocket이 같은 인증 세션을 사용하며, 실제 구독 승인을 확인한 뒤에만 정상 상태로 표시합니다.
- NAS 복구를 확인하는 동안 로컬 실시간 수신을 유지하고, 중앙 상류 구독이 준비된 뒤 전환해 재연결 체결 공백을 없앴습니다.
- 상세 키움 호출 로그는 날짜별 파일로 회전하며 queue 대기와 실제 HTTP 처리 시간을 분리해 기록합니다.

## 시장자료와 화면 복원

- 변경된 KRX·NXT 거래시간, 종가 단일가, NXT 정적 VI와 SOR 체결 구간을 공통 시장 일정에 반영했습니다.
- NAS 연결 앱은 중앙 분봉·일봉·기본정보·신고가·NXT 여부를 우선 사용하고 자동 시장자료 조회에서 키움 TR을 중복 호출하지 않습니다.
- 앱 시작과 NAS 복구 시 저장된 진행 분봉으로 1분·5분·60분·당일 거래대금을 복원합니다.
- TOP20 통계는 NAS 원본과 장후 확정 `ka20006` 전체시장 거래대금을 사용하며 15:30 종가 단일가를 포함합니다.
- 마지막 `0B` 시가총액을 NAS와 PC 직접 연결 DB에 보존해 장후 재시작 때 오래된 기본정보로 돌아가지 않게 했습니다.
- 상한가 가격에 도달한 종목은 등락률 셀 배경과 굵은 글씨로 강조하며 가격이 이탈하면 즉시 해제합니다.

## 뉴스와 앱 반응성

- NAS 뉴스 원문에서 저작권·기자 정보 뒤의 추천·댓글·포털 꼬리를 제거하고, 정제된 핵심 문장으로 비AI 요약과 방향 판정을 수행합니다.
- 주식·증권과 무관하거나 제목만 있는 검색 결과를 저장 전에 제외하고, 가격 급등락을 중계하는 기사와 실제 기업 사건을 구분합니다.
- 선택 종목의 뉴스는 60초 이상 지났을 때 즉시 갱신하며, 해당 종목의 원문·분류 작업을 다음 순서로 우선 처리합니다.
- 앱은 NAS 뉴스 전체 카탈로그를 반복 복제하지 않고 선택한 종목과 기사 근거만 읽어 장중 UI와 실시간 순위를 보호합니다.
- 상세 화면의 선택과 스크롤 위치를 주기적 목록 갱신 뒤에도 유지하고 실제 AI 결과가 있을 때만 AI 분석으로 표시합니다.

## 운영·진단

- NAS 설정에서 뉴스, 시장 누적자료, 연구, 계좌·주문, 기타 자료의 건수와 추정 저장 용량을 확인할 수 있습니다.
- Container Manager에는 중요한 로그만 남기고 상세 서버·키움 호출 로그는 날짜별 파일로 저장합니다.
- PostgreSQL 통합 검사에 인증, 계좌, 실시간, 연구, Shadow, 모의운용 저장 계약과 rollback 검증을 포함했습니다.
- API 계약, DB 스키마, 아키텍처, 모듈 지도, 개발 불변 규칙과 단계별 구현 보고서를 현재 코드에 맞춰 갱신했습니다.

## 업데이트 안내

- 기존 2.0.0의 로컬 설정과 SQLite 자료는 그대로 사용합니다.
- NAS를 사용하지 않는 PC 직접 연결 모드도 계속 지원합니다.
- NAS 기능을 사용하는 경우 앱 2.1.0과 `2026.09.21-market-cap-reference-v1` 누적 서버 소스를 함께 적용해야 합니다.
- 자동 모의운용은 READY 명세 게시만으로 주문을 시작하지 않으며 사용자가 계좌별로 시작해야 합니다.
