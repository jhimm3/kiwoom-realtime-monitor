## 중요한 구분

FID `228`의 **체결강도**는 키움이 제공하는 매수/매도 체결 관련 지표다. 명세의 사용자 정의 **거래강도**(기간 거래대금 ÷ 유통시가총액)는 다른 값이며 대체할 수 없다.

현재까지 확인된 자료로는 실시간 거래대금과 시가총액은 확보 가능하다. 유통비율은 아직 미확인이므로, 유통시가총액 기반 거래강도는 활성화하지 않는다.
