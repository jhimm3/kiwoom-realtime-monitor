## ka10016 신고저가 요청

`ka10016`은 시장 전체에서 기간별 신고가·신저가 종목을 직접 반환한다. 모의투자에서 아래 조건으로 100개 종목 응답을 확인했다.

```text
mrkt_tp=000 (전체), ntl_tp=1 (신고가), high_low_close_tp=1 (고저기준),
dt=20 (20거래일), stex_tp=1 (KRX)
```

반환 목록 키는 `ntl_pric`이며, 종목코드·종목명·현재가·고가·저가·거래량 등을 포함한다. `dt`에는 5·10·20·60·250 거래일을 넣을 수 있다.

따라서 화면의 신고가 표시는 각 기간별 `ka10016` 결과를 연속조회까지 수집·캐시한 뒤 Top 20의 `stk_cd`와 대조해 표시한다. `250`은 250거래일 기준이므로, 화면 문구는 정확히 **“250일 신고가(52주 근사)”**로 표기한다.

## ka10018 고저가근접 요청

당일 고가 근접 종목을 반환하며, 모의투자에서 200개 항목과 다음을 확인했다.

- 현재가, 등락률, 거래량
- 당일고가, 당일저가
- 매수·매도호가

이 API는 전체 시장의 당일 고가 근접 종목을 찾는 보조 기능으로 적합하다. 신고가 판정 API는 아니다. 이미 Top 20에 포함된 종목의 고가 근접 경고는 `0B`의 현재가와 당일고가로 직접 계산한다.

```text
고가까지 거리(%) = (기준 고가 − 현재가) ÷ 기준 고가 × 100
```
