# 유통비율 및 거래대금 원천 검증

검증일: 2026-08-14  
환경: 모의투자 (`mock`)  
대상: 삼성전자(`005930`)

## 1. 유통시가총액 원천

주식기본정보 `ka10001`에서 아래 필드가 실제로 값과 함께 수신됐다.

| 필드 | 의미 | 사용 |
| --- | --- | --- |
| `mac` | 시가총액 | 유통시가총액 계산 원천 |
| `dstr_stk` | 유통주식 | 참고·검증용 |
| `dstr_rt` | 유통비율 | 유통시가총액 계산 원천 |

따라서 사용자 정의 거래강도에 필요한 유통시가총액은 계산할 수 있다.

```text
유통시가총액 = 시가총액 × 유통비율 ÷ 100
거래강도(%) = 기간 거래대금 ÷ 유통시가총액 × 100
```

시가총액 단위는 실제 구현 전에 `ka10001.mac`과 `0B.311`을 비교하여 통일한다. `0B.311`은 공식 예제에서 “시가총액(억)”으로 표기된다.

| `0B` WebSocket | 누적거래대금(FID `14`) 존재 | 1·5·60분 거래대금의 기본 원천 |

## 3. 기간별 거래대금 계산 결정

영웅문 분당 거래대금 차트와 맞추기 위한 기본 산식은 다음과 같다.

```text
분당 거래대금(억원) = 거래량(V) × (고가(H) + 시가(O) + 저가(L) + 종가(C)) ÷ 4 ÷ 100,000,000
```

1·5·60분 거래대금은 1분 단위 계산값을 각각 1·5·60개 합산한다. 기간별 합산 후 OHLC 평균가격을 다시 계산하는 방식은 사용하지 않는다.

분봉 OHLCV는 실시간 `0B` 수신값으로 프로그램이 직접 구성한다.

- 시가: 해당 1분 창의 첫 체결가
- 고가: 해당 1분 창의 체결가 최댓값
- 저가: 해당 1분 창의 체결가 최솟값
- 종가: 해당 1분 창의 마지막 체결가
- 거래량: 해당 1분 창의 체결 거래량 합계

`0B`의 누적거래대금(FID `14`)은 분봉 계산값의 보조 검증용으로만 사용한다.

```text
1분 거래대금  = 해당 1분 OHLCV 산식 결과
5분 거래대금  = 최근 5개 1분 거래대금의 합
60분 거래대금 = 최근 60개 1분 거래대금의 합
1일 거래대금  = 당일 1분 거래대금의 합
```

장 시작·거래정지·재연결·누락된 체결이 발생하면 해당 1분 봉을 `불완전`으로 표시하고, 거래강도 계산에서 제외하거나 사용자에게 상태를 표시한다. 이 규칙은 구현 단계에서 테스트한다.

## 4. 결론

거래강도 계산의 원천 데이터는 확보됐다. 실제 분 단위 봉을 API에서 직접 받는 방식에는 의존하지 않으며, 실시간 체결을 모아 영웅문과 동일한 산식으로 분봉을 구성한다.
