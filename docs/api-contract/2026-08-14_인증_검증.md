# 키움 REST API 인증 검증

검증일: 2026-08-14  
환경: 모의투자 (`mock`)

## 결과

토큰 발급 API(`au10001`) 호출에 성공했다.

- 요청: `POST /oauth2/token`
- 인증 방식: `client_credentials`
- 확인 항목: App Key/Secret과 환경 구분이 일치할 때 토큰이 발급됨
- 보안 처리: App Key, Secret Key, 접근 토큰은 출력·파일 저장·Git 커밋 대상에서 제외

## 확인된 오류

초기에는 실전/모의 키와 환경 설정이 달라 `8030` 오류가 발생했다. 키 종류와 `KIWOOM_ENVIRONMENT` 값을 일치시켜 해결했다.
