## 2. Codex에 전달하는 방법

전체 방향을 검토할 때는 **전체본 하나**를 사용한다. 단계별 구현에서는 **이 안내 + 해당 분리본 + 필요한 다른 문서의 계약 부분**을 중심으로 전달한다. 전체본과 세 분리본을 모두 중복 입력할 필요는 없다.

이 패키지를 프로젝트 저장소에 넣더라도 기존 `AGENTS.md`나 프로젝트 지침을 자동으로 덮어쓰지 않는다. 실제 레포·NAS·계좌의 현재 구현 상태는 이 문서 작성 과정에서 감사하지 않았으므로, 문서에 등장하는 함수·엔드포인트·테이블을 존재하는 코드로 가정하지 않는다.

## 4. 작성·확인 범위

이 패키지는 개발 문서다. 코드를 실제 수정하거나 NAS 배포·백필·학습·모의투자·실거래를 실행한 결과가 아니다.

① 원문을 읽어 책임과 인터페이스를 맞췄으며, 새 문서의 계산 예제·JSON 문법·코드블록·파일 무결성을 점검했다. 경험적 기준은 확정된 시장 법칙이 아닌 연구 가설로 표시했다. 통계와 API 제공 범위가 미확인인 곳은 미확인 상태를 유지했다.

새 문서에 인용한 공식 자료는 각 문서의 참고 자료에 있다. 기존 ①의 참고문헌은 원문 그대로 보존했으며, 기존 ① 전체의 모든 외부 사실을 이번 작업에서 다시 검증했다는 뜻은 아니다.
