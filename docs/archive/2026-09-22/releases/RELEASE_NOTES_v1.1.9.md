# 1.1.9 변경 내역

- 부분 업데이트 적용을 PowerShell 스크립트에서 `UpdateHelper.exe`로 교체했습니다.
- 업데이트 도우미가 앱 종료 대기, ZIP 압축 해제, 파일 교체, 재실행을 독립적으로 처리합니다.
- 업데이트 목록과 ZIP 내부 경로가 설치 폴더 밖으로 벗어나지 않는지 도우미가 다시 검사합니다.
