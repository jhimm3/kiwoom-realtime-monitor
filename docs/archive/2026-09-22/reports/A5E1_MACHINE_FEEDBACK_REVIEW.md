# A5e1 — 사용자 복기와 분리된 기계 복기 revision

기준일: 2026-09-16. 로컬 구현·회귀 완료, NAS 누적 배포 전.

## 목적

A5d FeedbackEvidence를 사람이 쓴 복기나 전략 원본에 덮어쓰지 않고 반복 가능한 기계 복기로
바꾼다. 한두 번의 결과를 자동 개선 근거로 확대하지 않도록 최소 거래 수와 최소 활성 일수를
호출자가 명시한다.

## 입력과 출력

- 입력: 저장된 `journal_feedback_evidence/v1`, 최소 완료 거래 수, 최소 활성 일수.
- 출력: `journal_feedback_review/v1` 불변 revision.
- 같은 evidence와 같은 정책은 같은 review ID와 내용을 만든다.
- `derived_at`은 실행 시각이 아니라 원본 evidence의 동결 시각을 사용해 재시작 뒤에도 같다.

기계 복기는 확정 거래의 총손익, broker 비용 포함 순손익, 승/패/보합 수, 승률, 비용 비율,
최대 이익과 최대 손실을 기록한다. broker 순손익에 이미 포함된 비용을 다시 차감하지 않는다.

## 차단 경계

- A5d가 편향·사후 근거·최종결과 노출·체결/비용 미확정으로 부적격이면 `BLOCKED`다.
- 표본 기준을 채우지 못하면 `INSUFFICIENT_SAMPLE`다.
- 두 상태는 개선안 생성 입력으로 사용할 수 없다.
- 완료된 복기도 아직 전략 변경이나 주문을 만들지 않는다.

## 저장

기존 중앙 generic store의 비공개 `execution_feedback_reviews` 컬렉션을 사용한다.
repository는 같은 전략의 원본 evidence가 먼저 저장됐는지 확인하고, 원본과 review의 표본 정책으로
다시 계산한 값이 정확히 일치할 때만 저장한다. DB migration과 공개 API 추가는 없다.

## 검증

- A5e1 및 연관 체결·전진평가 회귀 34개 통과.
- 같은 입력의 동일 ID/내용, 비용 1회 반영, 표본 부족, 부적격 원본, 내용 변조,
  원본 없는 저장과 멱등 저장을 확인했다.
