# NAS Git 통합 시 보존한 원문

2026-10-18에 NAS 커밋 `3a59b18fef2e4982efcc2d75a3a50e9d1dd8cea2`를 최신 `main`에 통합하면서 문서 135개와 당시 배포 스크립트 원문을 보존했다. 문서는 Git blob을 그대로 이동했으며, 스크립트도 NAS 커밋의 원문을 별도로 저장했다. 양쪽 커밋 이력도 병합 부모로 유지한다.

이 폴더는 과거 기록이며 현재 개발 지시나 실행 경로가 아니다. 현재 문서는 [문서 안내](../../../README.md)를 따른다. 실행용 `deploy/synology/source-runtime.sh`는 최신 `main`의 DB 호환·실패 복구 처리를 유지한다. NAS의 생성 산출물·백업·운영 데이터 제외 항목은 현재 `.gitignore`에 합쳤다.

저장소 통합은 NAS 운영 릴리즈 배포나 재시작을 뜻하지 않는다.
