# 1.1.17 변경 내역

## 종목 뉴스와 AI 원문 분석

- 메인 순위표의 종목명을 더블클릭해 독립형 또는 메인창 연결형 뉴스창을 열 수 있습니다.
- 네이버 뉴스 API와 선택형 DART 공시 조회를 지원하며, API 키와 필터 설정은 현재 PC에 저장합니다.
- OpenAI·Google Gemini·Anthropic Claude 중 사용자가 직접 공급자·모델·API 키를 선택해 기사 원문을 요약하고 호재·악재 가능성을 판단할 수 있습니다.
- AI 분석 결과는 원문 요약, 판단 이유, 긍정·부정 근거, 관련성 점수와 신뢰도를 함께 표시하며 로컬 DB에 저장합니다.
- 자동분석은 뉴스 수집과 사건 분류가 끝난 뒤 백그라운드에서 실행되어 사용자가 보고 있는 뉴스 선택을 변경하지 않습니다.

## 중복 기사와 동일 사건 정리

- 같은 원문 주소를 완전 중복으로 제거하고, 최근 48시간의 제목·검색 요약이 유사한 기사를 동일 사건으로 묶습니다.
- 대표 기사 한 건만 기본 표시하고 `관련 기사 N건`에서 나머지 기사를 확인합니다.
- 금액·지분율·주식 수·계약 상대·임상 단계 및 사건 진행 단계가 다르면 후속 기사로 분리합니다.
- `검토 → 결정 → 체결 → 변경·취소` 단계를 구분하며 과거 사건을 다시 다룬 기사는 재언급 가능성을 표시합니다.
- DART 공시와 회사 공식 발표를 대표 기사로 우선하고, 특징주·급등·강세처럼 주가 반응만 다시 쓴 기사의 우선순위는 낮춥니다.
- AI는 대표 기사 한 건이 아니라 동일 사건으로 묶인 기사 전체를 읽고 최종 판단합니다.

## 뉴스창 사용성과 안정성

- 제목 더블클릭은 원문 열기, 판단 더블클릭은 수동 AI 분석으로 동작합니다.
- 뉴스창 열 표시, 광고·제공처 필터, AI 자동분석 건수와 판단 색상을 설정할 수 있습니다.
- 뉴스창과 뉴스 설정창의 마지막 위치·크기를 저장하고 다음 실행 때 복원합니다.
- AI 분석 실패는 메인 실시간 순위표를 멈추는 모달 창 대신 뉴스창 상태줄에 표시하고 다음 자동분석을 계속합니다.

## 실시간 분봉 기록

- 실시간 분봉 OHLCV와 함께 계산된 누적 거래대금을 DB에 저장하여 이후 비교와 진단에 재사용합니다.
