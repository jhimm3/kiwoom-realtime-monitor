# 1.1.19 변경 내역

## AI 분석 요청과 사용량 관리

- 뉴스 AI 분석을 `한 사건씩 요청` 또는 `여러 사건 묶음 요청` 중에서 선택할 수 있으며, 묶음 크기는 2~20건으로 설정할 수 있습니다.
- 묶음 요청은 여러 사건을 한 번의 공급자 API 호출로 보내므로 일일 요청 횟수를 절약합니다. 입력 토큰은 포함된 원문 전체 분량에 따라 사용됩니다.
- 실제 API 요청 횟수와 토큰 사용량을 날짜별로 저장하고 뉴스 설정과 상태 영역에서 확인할 수 있습니다.
- 일일 최대 분석 건수는 기사 수가 아니라 실제 공급자 API 요청 횟수를 기준으로 적용합니다.
- 최근 자동분석 범위 안에 이미 분석된 기사가 섞여 있어도 아직 분석하지 않은 기사까지 계속 찾습니다. 사용자가 선택한 위치부터 설정 건수만큼 이어 분석할 수도 있습니다.
- 같은 원문 URL이 여러 종목에 걸린 경우에도 현재 종목에 대한 영향이 AI 결과에 명확히 포함된 때만 안전하게 공통 결과를 재사용합니다.

## 뉴스창 조작과 배치

- 뉴스창을 독립 창, 메인창과 함께 앞으로, 메인창의 오른쪽·왼쪽·위·아래 고정 중에서 선택할 수 있습니다.
- 메인창 최소화 후 복원할 때 뉴스창도 안정적으로 함께 복원되며, 다른 프로그램의 창 순서를 흔드는 현상을 없앴습니다.
- 메인창의 외곽 프레임 위치·크기를 저장해 화면 가장자리와 작업표시줄을 기준으로 정확히 복원하고 고정합니다.
- 뉴스 자동분석 사용 여부를 뉴스창에서 바로 바꿀 수 있으며 설정 창의 값과 동기화됩니다.
- 저장 뉴스·증권 관련 뉴스 개수는 AI 작업 상태와 별도 줄에 유지됩니다.

## 뉴스 바로가기와 설정 백업

- 뉴스창에 최대 5개의 사용자 바로가기를 만들 수 있으며 입력한 항목만 표시합니다.
- 기본 바로가기로 `KIND`와 `공모주 일정`을 제공합니다. 이름과 주소는 뉴스 설정에서 변경할 수 있습니다.
- 설정 백업과 Google Drive 동기화에 뉴스 필터·표시 열·판단 색상·AI 공급자/모델·자동분석·요청 방식·묶음 크기·DART 사용 여부·바로가기를 포함합니다.
- 네이버 Client ID/Secret, AI API 키, DART API 키 같은 비밀값은 백업하거나 Drive에 올리지 않습니다.
- 뉴스 기사 전체 DB는 백업하지 않으며, API 비용 절약을 위한 AI 분석 결과는 기존처럼 별도 백업합니다.
