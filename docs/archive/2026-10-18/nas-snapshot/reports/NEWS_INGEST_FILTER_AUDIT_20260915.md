# 뉴스 신규 저장 필터 오프라인 감사

## 목적

NAVER query-set 수집 결과 중 검색 설명이 없는 제목뿐인 기사와 주식·증권·시황에 명백히 무관한 검색 잡음을 신규 저장 전에 제외한다. 본문을 읽기 전 단계에서 실행되므로 필요한 투자 자료를 잃지 않도록 보존 우선 기준을 사용한다.

## 2026-09-14 NAS 사본 적용 결과

- 평가 대상: query-set별 최신 GLOBAL 기사 12,906건
- 저장 유지: 12,876건(99.768%)
- 기존 종목 연결로 유지: 1,847건
- 시장·기업사건 문맥으로 유지: 11,029건
- 검색 설명이 없어 제외: 22건
- 명백한 무관 후보로 제외: 8건

처음 기준은 70건을 무관 후보로 골랐지만 고려아연 주총, 기업 소송, 재매각, 공장 투자, 수출 등 투자 판단 자료가 포함됐다. 기업 지배구조·소송·산업·생산·수출·규제 문맥을 보존 신호에 추가한 뒤 무관 후보는 아래 8건으로 줄었다.

- 미술 칼럼
- 조선 하청노동자 현장 기사
- 지역 의회 상임위 기사
- 건설현장 월례비 기사
- 해외 브랜드 팝업 기사
- 해외 전쟁 군사비 기사
- 방송사 매각 승인 관련 정치 기사
- 대학 교수 사회 기사

실제 수집에서는 최신 KRX 종목 카탈로그로 정확한 회사명이 확인되면 문맥 신호와 관계없이 보존한다. 따라서 위 사본에서 종목 연결이 없던 YTN처럼 상장 종목명이 정확히 나타나는 기사는 운영 환경에서 보존된다.

## 적용 계약

- 제목 또는 검색 설명이 비면 저장하지 않는다.
- 정확한 KRX 회사명이 확인되면 저장한다.
- 종목 연결이 없어도 시장·공시·재무·계약·지배구조·산업 문맥이 있으면 저장한다.
- 제외 건수는 source run 문서의 `raw_items`, `stored_items`, `skipped_title_only`, `skipped_irrelevant`에 기록한다.
- 기존 기사·본문·사건 이력은 참조 무결성 때문에 소급 삭제하지 않는다.

## 한계

이 필터는 최종 분류기가 아니다. 본문을 읽기 전에 확실한 검색 잡음만 제거한다. 99.9% 분류 정확도를 증명하려면 자동 참조 규칙과의 일치율이 아니라 사람이 판정한 독립 표본으로 오탐과 누락을 각각 측정해야 한다.
