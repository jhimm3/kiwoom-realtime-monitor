# Phase 2 REST 연결 기록

범위: 키움 REST 인증과 공통 요청 처리. 화면·주문 기능은 연결하지 않는다.

## 구현됨

- 프로젝트 최상위 `.env`에서 App Key, Secret Key, `mock`/`real` 환경 읽기
- OAuth 토큰 발급 및 만료 1분 전 자동 갱신
- 실행 중 메모리에만 토큰 보관 — SQLite·로그·화면에 저장하지 않음
- `api-id`, 인증 헤더, JSON POST를 한 곳에서 처리
- HTTP·연결·시간 초과·API 오류를 사용자에게 전달 가능한 예외로 변환
- 요청 사이 최소 0.3초 간격으로 순간 호출 제한 완화
- 단위 테스트: 토큰 재사용과 API 오류 처리

## 아직 연결하지 않음

- GUI의 연결 버튼과 상태 표시
- 순위/기본정보/신고가 조회 서비스
- WebSocket 실시간 체결 수신
