# Phase 4 화면 새로고침 기록

범위: 사용자가 누르는 버튼으로 순위·신고가 데이터를 화면 표에 표시한다.

## 구현됨

- 상단 `새로고침` 버튼
- 순위·종목·신고가·등락률을 표에 표시
- 조회 중·성공·실패 상태를 하단 상태줄에 표시
- `.env`가 없거나 설정이 틀리면 버튼을 비활성화하고 안내
- 테마·1분 강도·현재가는 아직 `-`로 표시

## 사용 방법

프로젝트 폴더에서 다음을 실행한 뒤 창의 `새로고침`을 누른다.

```powershell
.\.venv\Scripts\python.exe -m kiwoom_monitor
```
