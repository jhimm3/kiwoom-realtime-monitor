# Phase 5 WebSocket 기반 기록

범위: 주식체결(`0B`) 수신 메시지를 앱에서 사용할 수 있는 형태로 해석한다.

## 구현됨

- WebSocket 의존성(`websockets`) 추가
- `REAL`/`0B` 메시지에서 종목코드·현재가·누적거래량·누적거래대금·당일고가·체결시각 추출
- 가격은 수신 부호를 제거해 화면 표시 값으로 통일
- 메시지 해석 단위 테스트
- 새로고침한 Top 20을 별도 스레드에서 `0B`로 구독
- 수신 현재가를 표의 현재가 열에 실시간 반영
- PING 응답 및 창 종료 시 구독 종료

## 아직 미구현

- 체결 틱으로 1분 OHLCV와 거래대금 계산
- 연결이 끊겼을 때 자동 재연결
