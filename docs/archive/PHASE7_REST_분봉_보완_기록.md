# Phase 7 REST 분봉 보완 기록

범위: REST `ka10080`의 1분봉을 거래대금 계산기에 넣을 수 있는 형태로 변환한다.

## 확인 및 구현

- 모의투자에서 `ka10080` 1분봉 900개와 OHLC·거래량·체결시간 필드 확인
- 1분봉을 시간순 `MinuteOhlcv`로 변환
- REST 분봉을 계산기에 초기 주입(`seed`)할 수 있게 구현
- 5분·60분은 최근 5개·60개 1분봉 거래대금의 합으로 계산
- 1일은 해당 일자의 모든 수신·보완 1분봉을 합산

## 다음 작업

Top 20의 과거 분봉은 호출량이 크므로 화면을 멈추지 않는 백그라운드 보완 작업으로 연결한다. 완료 후 5분·60분·1일 값을 표에 추가한다.
