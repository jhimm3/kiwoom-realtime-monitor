Kiwoom Realtime Monitor

A desktop application that displays leading Korean stocks, themes, trading value, and trading strength in one place using the Kiwoom REST API and real-time trade data.

Google Drive synchronization

Only when a user chooses to enable it, the app backs up and restores settings and theme data to that user's Google Drive. The connection is made only after the user signs in to Google and grants consent.

Read the Privacy Policy

Key features

  • Real-time ranking view for the top 20 stocks through Kiwoom
  • Theme and stock management, plus text, spreadsheet, and image-OCR theme updates
  • Minute, hourly, and daily trading value and strength, with high-price proximity alerts
  • Optional Google Drive backup and restore for settings and themes

Data handling principles

API keys and Google sign-in tokens are stored locally on the user's computer in encrypted form. Even when Google Drive synchronization is enabled, the app does not upload API keys, sign-in tokens, or log files to Google Drive. The app does not send data to an external service or share it with third parties without the user's consent.
