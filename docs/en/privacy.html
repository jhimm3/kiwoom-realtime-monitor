Privacy Policy

Effective date: August 22, 2026

1. Overview

Kiwoom Realtime Monitor (the “App”) provides stock monitoring and optional Google Drive synchronization using only data entered or selected by the user. The App does not collect user data through a developer-operated server.

2. Data processed by the App

  • Kiwoom API settings entered by the user are stored locally on the user's computer in encrypted form.
  • Stocks, themes, and application settings entered or updated by the user are stored in a local database on the user's computer.
  • Only when the user connects and enables Google Drive synchronization, the App reads or writes settings and theme backup files in the user's Google Drive.
  • Google OAuth access and refresh tokens are stored locally on the user's computer in encrypted form.

3. Google Drive scope and purpose

The App requests only the https://www.googleapis.com/auth/drive.file scope. This scope is limited to files created by the App or files the user explicitly shares with the App. The App uses this permission only to create, read, and update the Kiwoom Realtime Monitor folder and its settings and theme backup files.

The App does not browse all files in Google Drive or read or change ordinary files that were not created for or shared with the App.

4. Data not uploaded to Google Drive

Kiwoom API keys, Google OAuth tokens, program logs, and local window size and column width preferences are not included in Google Drive synchronization.

5. Third-party sharing and transfers

The App developer does not collect, sell, or share user data. When Google Drive synchronization is used, only the selected settings and theme data are transferred to the user's own Google Drive. Kiwoom API communication takes place directly between the App and Kiwoom's API servers using the credentials entered by the user.

6. User choices and deletion

Google Drive synchronization is optional. Users can disconnect Google Drive or disable automatic upload and download at any time in the App. Disconnecting removes the locally stored OAuth token from that computer. Backup files already stored in Google Drive can be deleted directly by the user in Google Drive.

7. Security

The App uses operating-system encryption facilities to protect locally stored API keys and OAuth tokens. Users remain responsible for the security of their computer, Google Account, and backup files.

8. Contact

For questions about this Privacy Policy or data handling, please use GitHub Issues.

This policy may be updated when features or applicable requirements change.
