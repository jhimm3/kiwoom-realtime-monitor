키움 실시간 모니터

키움 REST API와 실시간 체결 데이터를 활용해 상위 종목의 순위, 테마, 거래대금과 거래강도를 한 화면에서 확인하는 데스크톱 프로그램입니다.

Google Drive 동기화

사용자가 선택한 경우에만 설정과 테마 데이터를 사용자의 Google Drive에 백업·복원합니다. Google Drive 연결은 사용자의 Google 계정 로그인과 명시적 동의 후에만 이루어집니다.

주요 기능

  • 키움 실시간 상위 20종목 순위 조회와 체결 기반 표시
  • 테마·종목 관리, 텍스트·엑셀·이미지 OCR 기반 테마 업데이트
  • 분·시간·일 거래대금 및 거래강도, 최고가 근접 알림
  • Google Drive를 이용한 선택적 설정·테마 백업과 복원

데이터 처리 원칙

API 키와 Google 로그인 토큰은 사용자 컴퓨터에 암호화하여 저장합니다. Google Drive 동기화를 켠 경우에도 API 키, 로그인 토큰, 로그 파일은 Drive에 업로드하지 않습니다. 앱은 사용자의 동의 없이 외부 서버로 데이터를 전송하거나 제3자에게 판매·공유하지 않습니다.
