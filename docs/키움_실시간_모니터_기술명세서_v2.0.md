# 키움 실시간 종목순위·테마·거래강도 모니터 기술명세서 v2.0

> 작성일: 2026-08-14  
> 대상: Windows용 Python/PySide6 데스크톱 앱  
> 기준: 현재 구현 상태. 최초 v1.0 명세와 이후 확정된 사용성·안정성 요구를 통합한다.

## 1. 목적

키움 REST API와 WebSocket을 이용해 실시간 종목순위 상위 20개를 표시하고, 사용자 테마·거래대금·거래강도·기간 최고가 근접도를 한 화면에서 판단하는 모니터다.

- 매매 주문 기능은 제공하지 않는다.
- 실행파일 배포는 장중 실측 검증 후 별도로 진행한다.
- API 키는 프로젝트의 `data/api.env`에 암호화하여 보관하며 Git에 포함하지 않는다.

## 2. 기술 구성

| 구분 | 구성 |
| --- | --- |
| 언어/GUI | Python 3, PySide6 |
| 저장소 | SQLite (`data/monitor.db`) |
| API | 키움 REST API + WebSocket 0B 실시간 체결 |
| 테마 입력 | Excel `.xlsx` (종목명, 테마) |
| 로그 | `data/logs`의 날짜별 로그 |
| 테스트 | `unittest` |

## 3. 화면과 사용자 기능

### 3.1 메인 표

기본 표시 열은 순위, 종목, 테마, 등락률, 1분강도, 현재가, 신고가다. 아래 열은 표 구성에서 표시·숨김·순서 변경이 가능하다.

- 1/5/60분 및 1일 거래대금(억)
- 1/5/60분 및 1일 거래강도
- 신고가(선택한 5/20/250일 기간의 최고가)
- 신고가%(현재가와 신고가의 거리)

등락률은 상승 시 빨간 글자, 하락 시 파란 글자로 표시한다. 종목 칸 오른쪽 아래의 작은 빨간 삼각형은 NXT 거래 가능 종목을 뜻한다.

### 3.2 반응형 표

- 반응형 UI와 고정 UI/공간 확장 모드를 제공한다.
- 창 크기, 글자 크기, 행 높이, 테마 배지 크기·여백, 소수점 자릿수를 설정한다.
- 사용자가 열 폭을 조정하면 30초 동안 자동 열 맞춤을 멈춘다.
- 열 머리글 메뉴 및 표 구성 창에서 열 표시·순서·폭을 조정한다. 표 구성 창은 드래그와 위/아래 버튼을 모두 지원한다.

### 3.3 테마 관리

- 종목별 복수 테마를 SQLite에 저장한다.
- 테마 열을 눌렀을 때만 해당 종목의 테마를 편집한다.
- 테마 배지는 기본 색상 또는 종목별 개별 색상을 사용한다. 추천 색상과 자동 글자색을 제공한다.
- Excel 업데이트는 `종목/테마 관리`에서 실행한다. 기본 구분자는 `,`, `/`, `|`, `;`이며 추가 구분자를 설정할 수 있다.
- Excel은 현재 테마를 대체하는 입력이다. 종목명이 키움 종목명과 다르면 확인·수정·별칭 저장 과정을 거친다.
- 신규 추가·텍스트·Excel·이미지 OCR은 각자 저장되는 추가 구분자와 제외 테마를 사용한다. Excel은 미리보기 전에 수정 단계를 제공하고, 이미지 OCR은 여러 장을 한 번에 처리할 수 있다.
- 텍스트 입력의 `#` 소분류는 사용자가 선택한 경우에만 대분류와 함께 별도 테마로 추가한다.
- 한 칸에 여러 종목명이 붙은 경우 전체 분리 후보를 먼저 제시하고, 정확히 확인된 종목을 제외한 나머지 조각은 테마 문맥을 표시한 유사검색으로 보정한다.
- KRX 상장목록과 KIND `상호변경안내` 공시를 백그라운드로 동기화한다. 과거 종목명 연결은 자동 확정하지 않고 사용자의 승인 후 별칭으로 저장한다.

### 3.4 신고가 근접 알림

- 기준 기간은 5일, 20일, 250일 중 하나를 선택한다.
- 관심/주의/불의 세 단계 근접 퍼센트를 개별 설정한다.
- 단계별 아이콘은 문자 또는 PNG/JPG 등 이미지로 바꿀 수 있다.
- 단계별 사운드를 WAV/MP3/OGG/M4A 파일로 지정할 수 있으며, 단계에 새로 진입할 때 한 번 재생한다.
- 전체 행 강조 단계는 사용자가 관심/주의/불 중에서 선택한다.
- 신고가 값이 없으면 근접 강조를 하지 않는다.

### 3.5 설정·운영

- 모의/실전 API 키를 모두 저장하고 실행 중 환경을 선택한다.
- API 키 입력값은 가리고, 로컬 암호화 파일에만 보관한다.
- API 키가 없으면 앱 시작 시 API 설정 창을 먼저 연다.
- 기본 설정의 관리 탭에서 로그 폴더, 종목/테마 관리, API 설정을 연다.
- 설정 백업/복원은 JSON 파일로 제공한다. 화면 설정, 열 구성, 테마·색상, 종목명 별칭을 포함하며 API 키·로그·실시간/분봉 데이터는 제외한다.

## 4. API와 데이터 사용

| 용도 | API | 사용 시점 | 주요 데이터 |
| --- | --- | --- | --- |
| 접근 토큰 | `au10001` | 필요 시 자동 재발급 | Access token |
| 실시간 순위 | `ka00198` | 설정한 순위 기준 시각 | 상위 20종목 |
| 실시간 체결 | WebSocket `0B` | 순위 종목 구독 후 지속 | 현재가(10), 등락률(12), 누적거래량(13), 체결대금(14), 한 건 체결량(15), 당일 고가(17), 체결시각(20) |
| 1분 분봉 | `ka10080` | 순위·실시간 연결 후 종목별 보완 | 시가·고가·저가·종가·거래량 |
| 기본정보 | `ka10001` | 분봉·기간 최고가 조회 후, 하루 1회 캐시 | 시가총액, 유통비율, 250일 최고가 |
| 일봉 최고가 | `ka10081` | 기본정보 전, 종목별 | 5일·20일 최고가 및 직접 일별 거래대금 |
| NXT 가능 여부 | `ka10100` | 하루 1회 캐시 | `nxtEnable` Y/N |
| 신고가 목록 | `ka10016` | 앱 시작 시 1회 및 신고가 새로고침 버튼 | 선택 기간 신고가 종목 |

### 4.1 API 작업 우선순위

1. 실시간 순위 조회
2. 순위 종목의 0B WebSocket 구독
3. `ka10080` 분봉 보완
4. `ka10081` 5/20일 최고가 및 전일 거래대금
5. `ka10001` 기본정보 및 250일 최고가
6. `ka10100` NXT 가능 여부
7. `ka10016` 신고가 목록

0B 구독 완료 신호 뒤에 후속 REST 작업을 시작한다. 장외 또는 연결 실패 시에는 5초 뒤에 후속 작업을 시작해 정지하지 않도록 한다.

### 4.2 요청 안정성

- REST 요청은 단일 잠금과 요청 간격을 사용한다.
- HTTP 429, 시간초과, 연결 강제 종료에는 지연 후 재시도한다.
- WebSocket은 로그인, PING 응답, 연결 종료 후 재연결을 처리한다.
- 순위 응답이 20개보다 적으면 최대 2회 재시도한다.
- API 오류는 앱 종료 대신 상태 표시줄과 날짜별 로그로 남긴다.

## 5. 거래대금과 거래강도

### 5.1 1분 거래대금

앱 실행 시 `ka10080`으로 당일 지난 분봉을 채운다. 이후에는 0B 체결을 1분 단위로 집계한다.

- 시가: 해당 분의 첫 체결가
- 고가/저가: 해당 분의 최대/최소 체결가
- 종가: 해당 분의 마지막 체결가
- 거래량: 0B `15` 한 건 체결량의 합계. `15`가 없을 때만 `13` 누적거래량의 증가분을 사용한다.

각 분봉 거래대금(억)은 아래 식을 사용한다.

```text
거래대금(억) = 거래량 × (고가 + 시가 + 저가 + 종가) ÷ 4 ÷ 100,000,000
```

1분은 현재 분봉, 5분·60분은 최근 해당 개수 분봉의 합계, 1일은 당일 분봉 합계다. 설정에서 `직전 완료 구간`을 선택하면 진행 중인 현재 분은 제외한다.

### 5.2 거래강도

```text
유통시가총액 = 시가총액 × 유통비율 ÷ 100
거래강도(%) = 기간 거래대금 ÷ 유통시가총액 × 100
```

1분·5분·60분·1일은 서로 다른 기간 거래대금으로 계산하므로 값이 독립적이다. 기간별 관심/주의/불 기준과 거래대금 경고 기준을 설정할 수 있다.

## 6. 최고가 처리

- 5일·20일 최고가는 `ka10081` 일봉의 기간별 고가 최댓값이다. 전일 거래대금은 같은 응답의 `trde_prica` 직접값을 사용한다.
- 250일 최고가는 `ka10001`의 기본정보 값이다.
- 실시간 0B 당일 고가가 더 높으면 화면의 신고가 계산에 반영한다.
- `신고가 새로고침`은 신고가 목록을 다시 불러온 뒤 순위를 다시 갱신한다.
- 상장 후 전체 기간 최고가는 제공하지 않는다.

## 7. 저장 구조

| 테이블/파일 | 내용 |
| --- | --- |
| `settings` | 모든 사용자 설정 |

| `kind_name_disclosures` | KIND 상호변경 공시 상세 처리 대기열 |
| `themes`, `stock_themes` | 테마·색상·종목 연결 |
| `data/api.env` | 암호화된 모의/실전 API 키 (Git 제외) |
| `data/logs` | 날짜별 운영 로그 (Git 제외) |

## 8. 실행과 검증

개발 환경 실행:

```powershell
.\.venv\Scripts\python.exe -m kiwoom_monitor
```

검증:

```powershell
.\.venv\Scripts\python.exe -m compileall -q src tests
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

장중 검증 시 영웅문과 동일한 종목을 기준으로 순위, 1/5/60분 거래대금, 거래강도, 기간 최고가를 비교한다. KRX(09:00~15:30)와 실전 NXT(08:00~09:00, 15:30~20:00)도 각각 확인한다.

## 9. 현재 제외 또는 후속 검토 항목

- 실행파일(PyInstaller) 생성: 장중 실측 검증 후 진행
- 주문·계좌·조건검색 기능: 범위 밖
- 상장 후 전체 기간 최고가: 제외
- `ka10080` REST 연속조회: 최근 분봉 한 응답 부족이 실측되면 추가
- 관심종목 고정, CSV 내보내기, 단축키, 알림 이력: 필요 시 별도 기능으로 검토
