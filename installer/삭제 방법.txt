키움 실시간 모니터 삭제 방법

1. Windows 설정 > 앱 > 설치된 앱에서 "키움 실시간 모니터"를 찾아 제거합니다.
   또는 설치 폴더의 "unins000.exe"를 실행합니다.

2. 완전히 삭제하려면 설치 폴더 안의 data 폴더도 직접 삭제합니다.
   data 폴더에는 아래 개인 데이터가 들어 있습니다.
   - 암호화된 API 키 설정(api.env)
   - 테마, 열 순서, 화면 설정(monitor.sqlite3)
   - 신고가 알림 소리와 로그

3. 설정을 보관하려면 삭제 전에 앱의 기본 설정 > 관리 > 설정 백업 저장을 사용합니다.

주의: data 폴더를 삭제하면 저장된 API 키와 모든 개인 설정을 되돌릴 수 없습니다.
